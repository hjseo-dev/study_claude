# Jira 배경 초안 작성

`spec-writer`(메인 스킬)의 산출물이나 지금 대화에서 나온 내용을 바탕으로,
Jira 티켓에 그대로 붙여넣을 수 있는 배경/목적 설명 초안을 작성한다.

## 1. 원본 확인

1. 현재 프로젝트의 `docs/analysis/` 폴더에서 가장 최근 수정된 분석 문서를
   찾는다. 여러 개면 어떤 요구사항 건인지 사용자에게 물어본다.
2. 찾았으면 그 문서의 **변경 유형 / Who / What / Where / Why**를 읽어서
   재료로 쓴다.
3. 분석 문서가 없거나 이번 요구사항과 안 맞으면, 대화에서 나온 내용을
   재료로 쓴다. 배경/목적이 명확하지 않으면 사용자에게 직접 물어본다 —
   지어내지 않는다.

## 2. Jira 초안 작성

아래 형식으로 정리해서, **복사해 붙여넣기 쉽게 마크다운 코드블록으로
감싸서** 보여준다:

```
제목: {요구사항을 한 줄로}

[배경]
{Why — 왜 이 작업이 필요한지}

[목적/기대효과]
{이 변경으로 무엇이 해결/개선되는지}

[영향 범위]
{Where 요약 — 내부 모듈 + 영향받는 다른 시스템이 있으면 그것도}

[변경 유형]
{버그 수정 / 기능 개선 / 신규 기능 / 리팩토링 / 성능 개선 / 기술 부채 해소 / 보안 패치 중 하나}
```

- 원본 분석 문서에 없는 내용을 지어내서 채우지 않는다 — 빈 부분은 사용자에게
  물어보거나 "확인 필요"라고 남겨둔다.
- 문서를 갱신할 필요가 있으면(예: 사용자가 이 자리에서 배경을 더 자세히
  말해줌) 원본 분석 문서에도 반영할지 물어보고, 원하면 `docs/analysis/`의
  해당 파일을 업데이트한다.
