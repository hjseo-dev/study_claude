# stock-picks 사용법

관심 있는 분야 키워드(최대 5개)를 입력하면, 각 분야와 관련된 국내(코스피/
코스닥) 종목 중 **시가총액이 가장 큰 3개**씩 알려주는 스킬입니다.
투자자문이 아니라 객관적 지표(시가총액) 기준 정보 제공용입니다.

## 1. 사전 준비: 인증키 발급

**STOCK_API_KEY** 하나가 필요합니다.

1. [data.go.kr](https://www.data.go.kr) 가입
2. "금융위원회_주식시세정보" 검색 후 활용신청 (무료, 보통 바로 또는 빠르게 승인)
3. 마이페이지 > 데이터 활용 > Open API 개발계정 상세보기에서 **서비스키**
   확인 후 `STOCK_API_KEY`로 등록

PowerShell (영구 설정, 새 터미널부터 적용):

```powershell
setx STOCK_API_KEY "발급받은_서비스키"
```

## 2. 호출 방법

```
/stock-picks:stock-picks
```

그냥 이렇게 인자 없이 호출하면 "관심 있는 분야를 최대 5개까지 알려주세요"
라고 먼저 물어봅니다. 거기에 답하면(예: "2차전지, AI, 로봇") 분야별 결과를
보여줍니다.

"2차전지 관련 주식 알려줘", "AI 분야 대장주 뭐야" 같은 말로도 자동
실행되고, 이 경우엔 이미 말한 키워드를 다시 묻지 않습니다.

## 3. 데이터 소스

- **테마/종목 목록**: 네이버 금융 "테마별 시세" 페이지(로그인 불필요, 약
  270여 개 테마 — 2차전지, AI챗봇, 로봇 등 투자자들이 실제 쓰는 분야명)
- **시가총액**: 공공데이터포털 "금융위원회_주식시세정보" API. 실시간이
  아니라 **최근 영업일 기준**(당일 오후 1시 이후 전날 데이터 갱신)입니다.

## 4. 결과 예시

```
📌 2차전지
⭐ LG에너지솔루션 — 시가총액 약 92조원
🥈 삼성SDI — 시가총액 약 15조원
🥉 에코프로비엠 — 시가총액 약 8조원

시가총액 기준 객관적 순위이며 투자 추천이 아닙니다.
```

## 5. 한계 / 유의사항

- **국내(코스피/코스닥)만** 지원합니다. 해외 종목은 안 됩니다.
- 키워드와 정확히 일치하는 테마가 없으면 비슷한 후보를 골라 쓰거나, 애매하면
  다시 물어봅니다. 그럴듯한 테마가 아예 없으면 "매칭 실패"로 솔직히 안내합니다.
- 시가총액 API 필드명(`mrktTotAmt` 등)은 공개 문서 기준이고 실제 서비스키로
  검증된 적은 없습니다. 값이 이상하게 나오면 원본 응답 구조가 문서와 다를 수
  있으니 확인이 필요합니다.
- 이 스킬은 **투자자문이 아닙니다.** 매수/매도 시점이나 개인 맞춤 조언은
  제공하지 않습니다.
