# 기상청 단기예보(getVilageFcst) 필드 참고

`https://apis.data.go.kr/1360000/VilageFcstInfoService_2.0/getVilageFcst` 응답의
`category` 코드 의미. umbrella 스킬이 쓰는 초단기실황/예보(`getUltraSrtNcst`/`getUltraSrtFcst`)와는
다른 엔드포인트로, 최대 3일치·3시간 간격 예보와 일 최저/최고기온(TMN/TMX)을 제공한다.

| 코드 | 의미 | 단위/형식 |
| --- | --- | --- |
| POP | 강수확률 | % |
| PTY | 강수형태 | 0 없음, 1 비, 2 비/눈, 3 눈, 4 소나기, 5 빗방울, 6 빗방울눈날림, 7 눈날림 |
| SKY | 하늘상태 | 1 맑음, 3 구름많음, 4 흐림 |
| TMP | 1시간 기온 | ℃ |
| TMN | 일 최저기온 | ℃ — **0200(02시) 발표 회차에만 포함** |
| TMX | 일 최고기온 | ℃ — **0500(05시) 발표 회차에만 포함** |
| REH | 습도 | % |
| WSD | 풍속 | m/s |
| VEC | 풍향 | deg |
| PCP | 1시간 강수량 | 범주형 문자열(mm), "강수없음" 포함 |

## TMN/TMX를 가져올 때 주의할 점

`getVilageFcst`는 발표 회차(base_time: 0200/0500/0800/1100/1400/1700/2000/2300)별로
그 시점 기준 최대 3일치 예보를 준다. 하지만 **오늘의 TMN은 0200 회차에만, 오늘의 TMX는
0500 회차에만** 포함된다 — 그 이후 회차(0800 이후)로 오늘 데이터를 조회하면 TMN/TMX
항목 자체가 응답에 없다.

그래서 "오늘 최저/최고기온"을 정확히 가져오려면, 현재 시각과 상관없이 **오늘 날짜의
0200 회차(TMN용)와 0500 회차(TMX용)를 각각 별도로 조회**해야 한다. 단, 아직 그 시각이
지나지 않았다면(예: 새벽 3시에 조회) 해당 회차가 아직 발표 전이라 값이 없을 수 있다 —
이 경우 "아직 발표 전"으로 표시한다.

현재 기온/하늘상태/강수확률 등 그 외 값은 가장 최근 발표 회차를 그대로 쓰면 된다.
