# home-eta 사용법

자취방 -> 본가 자차 이동 시간을, 지금 바로 / 지금부터 30분 / 1시간 / 1시간
30분 뒤 각각 출발하는 경우로 나눠서 알려주는 스킬입니다. (무료도로 우선,
톨게이트 회피)

## 1. 사전 준비: TMAP_API_KEY 발급

1. [openapi.sk.com](https://openapi.sk.com)(SK Open API)에서 가입
2. "T map" 관련 앱 생성 → appKey 발급 (무료 등급으로 충분)
3. 환경변수로 등록 (PowerShell, 영구 설정 - 새 터미널부터 적용됨)

   ```powershell
   setx TMAP_API_KEY "발급받은_appKey"
   ```

   방금 설정했다면 **새 터미널을 열어야** 반영됩니다. 기존 터미널에서 바로
   써야 한다면 그 세션에서만 `$env:TMAP_API_KEY = "발급받은_appKey"`로 임시
   지정할 수 있습니다.

## 2. 호출 방법

Claude Code에서 아래 슬래시 명령을 입력합니다.

```
/wlabs:home-eta
```

(플러그인 이름과 스킬 이름을 콜론으로 이은 형식입니다. `/home-eta`만 입력하면
동작하지 않습니다.)

이 스킬은 "본가 가는데 얼마나 걸려?" 같은 말을 해도 자동으로는 실행되지
않습니다 (SKILL.md의 `disable-model-invocation: true` 설정). 위 슬래시
명령으로 명시적으로 불러야 합니다.

## 3. 첫 실행 시: 주소 입력

처음 실행하면 저장된 주소가 없어서 Claude가 "자취방 주소"와 "본가 주소"를
물어봅니다. 도로명 또는 지번 주소면 충분하고, 동/호수 같은 상세 주소는
필요 없습니다.

- 주소는 이 리포지토리(GitHub에 공개됨) 안에는 저장되지 않습니다.
- 대신 사용자 홈 디렉터리의 로컬 파일에만 저장됩니다.

  ```
  %USERPROFILE%\.claude\skill-data\home-eta\locations.json
  ```

이 파일은 리포 밖에 있어서 git으로 추적/커밋되지 않고, 이 리포를 clone한
다른 사용자에게도 공유되지 않습니다. 각자 자기 컴퓨터에서 한 번씩 자기
주소를 입력해 세팅하게 됩니다.

## 4. 결과 예시

```
🚗 지금 바로(15:00) 출발하면 42분 걸려서 15:42쯤 도착해요.
🚗 지금부터 30분 뒤(15:30) 출발하면 40분 걸려서 16:10쯤 도착해요.
🚗 지금부터 1시간 뒤(16:00) 출발하면 38분 걸려서 16:38쯤 도착해요.
🚗 지금부터 1시간 30분 뒤(16:30) 출발하면 35분 걸려서 17:05쯤 도착해요.
⭐ 1시간 30분 뒤 출발이 가장 빨라요.
```

## 5. 주소를 바꾸고 싶을 때

"주소 다시 설정해줘", "이사했어" 등으로 요청하면 새 주소 두 개를 물어보고
기존 저장 파일을 덮어씁니다.

## 6. 자주 겪는 문제

- **`TMAP_API_KEY가 설정되어 있지 않습니다` 오류**: 위 1번 단계를 다시
  확인하세요. `setx`로 설정한 직후라면 새 터미널(새 Claude Code 세션)을
  열어야 반영됩니다.
- **거리/시간이 말이 안 되게 짧거나 김**: 주소 지오코딩이 엉뚱한 곳으로
  잘못 매칭됐을 가능성이 있습니다. 도로명이 정확한지(오타 없는지) 확인하고
  "주소 다시 설정해줘"로 재입력해보세요.
