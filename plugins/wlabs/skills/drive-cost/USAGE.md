# drive-cost 사용법

출발지에서 목적지까지 자차로 **왕복**할 때 드는 통행료(톨비)와 기름값을
계산해주는 스킬입니다. 총 왕복 km, 왕복 통행료, 통과하는 요금소/IC 이름,
왕복 기름값, 총 합계를 알려줍니다.

> 통행료는 경로 전체 합계만 정확합니다. 게이트(요금소)별 개별 금액은 Tmap API가
> 제공하지 않아서, 통과하는 요금소/IC **이름**만 참고용으로 함께 보여줍니다.

## 1. 사전 준비: 인증키 3종 발급

### ① TMAP_API_KEY

1. [openapi.sk.com](https://openapi.sk.com)(SK Open API) 가입
2. "T map" 관련 앱 생성 → appKey 발급 (무료 등급으로 충분)
3. home-eta 스킬을 이미 쓰고 있다면 **같은 키를 그대로 재사용**하면 됩니다.

### ② FUEL_API_KEY (연비 자동 조회용)

1. [data.go.kr](https://www.data.go.kr) 가입
2. "한국에너지공단_자동차 표시연비 목록 조회 서비스" 검색 후 활용신청
3. 승인되면 마이페이지 > 데이터 활용 > Open API 개발계정 상세보기에서
   **서비스키**를 확인해 `FUEL_API_KEY`로 등록합니다 (시스템/Machine-level
   환경변수로 등록 — `setx ... /M`, 관리자 권한 필요).

   요청 기본 주소(`https://apis.data.go.kr/B553530/CAREFF`)는 스크립트에 이미
   고정되어 있어서 따로 설정할 필요가 없습니다.

   > 이 키를 아직 발급받지 않았거나 조회가 실패해도 괜찮습니다. Claude가
   > 사용자에게 직접 차량 연비(km/L)와 유종을 물어보는 방식으로 대체합니다.

### ③ OPINET_API_KEY (실시간 유가 조회용)

1. [opinet.co.kr](https://www.opinet.co.kr) 가입
2. 유가정보 오픈API 페이지에서 무료 인증키(certkey) 발급

### 환경변수 등록 (PowerShell, 영구 설정 — 새 터미널부터 적용)

```powershell
setx TMAP_API_KEY "발급받은_appKey"
setx FUEL_API_KEY "발급받은_서비스키" /M
setx OPINET_API_KEY "발급받은_certkey"
```

방금 설정했다면 **새 터미널(새 Claude Code 세션)**을 열어야 반영됩니다.

## 2. 호출 방법

```
/wlabs:drive-cost
```

또는 "서울역에서 부산역까지 왕복 톨비랑 기름값 알려줘" 같은 말로도 자동
실행됩니다.

## 3. 첫 실행 시: 차량 정보 입력

처음 실행하면 톨비/거리는 바로 나오지만, 저장된 차량 정보가 없어서 기름값은
빠집니다. Claude가 "차종이 뭐예요?"라고 물어보면 모델명을 답하세요
(예: "아반떼 CN7"). 한국에너지공단 API로 연비를 자동 조회한 뒤 확인을 받고
저장합니다. API 조회가 안 되면 연비(km/L)와 유종을 직접 입력해도 됩니다.

- 차량 정보는 이 리포지토리(GitHub에 공개됨) 안에는 저장되지 않습니다.
- 대신 사용자 홈 디렉터리의 로컬 파일에만 저장됩니다.

  ```
  %USERPROFILE%\.claude\skill-data\drive-cost\car.json
  ```

## 4. 결과 예시

```
🚗 총 왕복 거리: 650.8km (편도 325.4km)
🛣️ 왕복 통행료: 45,600원 (통과 추정 요금소/IC: 서울요금소, 부산IC)
⛽ 왕복 기름값: 79,560원 (휘발유, 리터당 1,650원, 연비 13.5km/L 기준)
⭐ 왕복 총 비용: 약 125,160원
```

## 5. 차량 정보를 바꾸고 싶을 때

"차 바꿨어", "차량 정보 다시 설정해줘" 등으로 요청하면 새 차종을 물어보고
기존 저장 파일을 덮어씁니다.

## 6. 자주 겪는 문제

- **`TMAP_API_KEY가 설정되어 있지 않습니다` 오류**: 위 ① 단계를 다시
  확인하세요. `setx` 직후라면 새 터미널을 열어야 반영됩니다.
- **출발지/목적지 좌표를 못 찾음**: 너무 모호한 지명이면 실패할 수 있습니다.
  정확한 도로명 주소이거나 잘 알려진 역/건물명으로 다시 시도해보세요.
- **기름값이 안 나옴(`fuel.error`)**: `OPINET_API_KEY` 미설정이거나 오피넷
  응답에서 유종(휘발유/경유/LPG) 이름이 일치하지 않는 경우입니다. 메시지에
  나온 원인을 확인하세요.
- **톨비가 예상보다 훨씬 적거나 0원**: 무료도로 위주 경로로 잡혔을 수
  있습니다(고속도로가 아닌 경로). 출발지/목적지가 정확한지 확인하세요.
