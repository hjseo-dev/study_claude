# cafe-with-study 사용법

특정 지역에서 공부/작업하기 좋은(콘센트, 조용함, 1인 이용 등) 카페를 찾아
추천해주는 스킬입니다.

## 1. 사전 준비: 네이버 API 키 발급

2026년 네이버 검색 오픈API 개편으로, 예전 개발자센터(developers.naver.com)의
"검색" 카테고리는 신규 발급이 막혔습니다. 지금은 **네이버클라우드 플랫폼(NCP)의
"NAVER API HUB"**를 통해서만 새로 신청할 수 있습니다.

1. [ncloud.com](https://www.ncloud.com)에서 네이버클라우드 플랫폼 계정 생성/로그인
2. 콘솔에서 **Services > AI·NAVER API** 메뉴로 이동
3. Application 등록 → 사용 API에서 **지역검색 API** 선택
4. 발급받은 **Client ID**, **Client Secret**을 환경변수로 등록 (PowerShell,
   영구 설정 - 새 터미널부터 적용됨)

   ```powershell
   setx NAVER_HUB_KEY_ID "발급받은_클라이언트_ID"
   setx NAVER_HUB_KEY "발급받은_클라이언트_시크릿"
   ```

   방금 설정했다면 **새 터미널을 열어야** 반영됩니다. 기존 터미널에서 바로
   써야 한다면 그 세션에서만 `$env:NAVER_HUB_KEY_ID = "..."` /
   `$env:NAVER_HUB_KEY = "..."`로 임시 지정할 수 있습니다.

   **참고**: 지역검색 API의 정확한 요청 경로는 공식 문서로 100% 확인하지
   못했고, 다른 검색 API(`/search/v1/news`)와 같은 패턴으로 `/search/v1/local`
   일 것으로 추정해 스크립트에 넣어뒀습니다. 실행했을 때 404 오류가 나면,
   NCP 콘솔에서 지역검색 API를 선택했을 때 보여주는 예제 코드의 실제 경로를
   확인해서 `scripts/search_naver_places.js`의 `API_URL` 값을 그걸로 고쳐야
   합니다.

## 2. 호출 방법

Claude Code에서 아래 슬래시 명령을 입력합니다.

```
/wlabs:cafe-with-study
```

(플러그인 이름과 스킬 이름을 콜론으로 이은 형식입니다.) "공부하기 좋은 카페
찾아줘" 같은 말로는 자동 실행되지 않습니다(`disable-model-invocation: true`)
— 위 슬래시 명령으로 명시적으로 불러야 합니다.

이 스킬은 서브에이전트(포크)로 분리 실행됩니다. 검색/스크래핑 원본 데이터는
메인 대화창에 나오지 않고, 최종 추천 요약만 전달됩니다.

## 3. 실행하면

- 매번 지역(동네명/역명 등)을 물어봅니다. 저장하지 않으므로 매번 새로
  알려주셔야 합니다. (예: "강남역 근처", "홍대")
- 네이버 지역검색 API로 카페 후보를 찾고(한 번에 최대 5개), 각 카페의 네이버
  플레이스 리뷰 키워드 태그를 확인해서 공부/작업 관련 태그가 있는 곳 위주로
  정렬해 상위 몇 곳을 보여줍니다.

## 4. 한계 (읽어두시면 좋아요)

- **테이블 수/매장 크기 같은 물리적 정보는 제공하지 않습니다** — 그런 데이터를
  구조화해서 주는 공개 API가 없습니다.
- 리뷰 키워드 태그는 **네이버 플레이스 페이지를 비공식으로 읽어오는 방식**이라,
  네이버가 페이지 구조를 바꾸면 일부/전체 카페에서 태그를 못 읽어올 수
  있습니다. 이 경우 해당 카페는 "리뷰 확인 불가"로만 표시됩니다.
- LLM으로 리뷰 문장을 읽고 판단하지 않고, "콘센트/조용/스터디/카공/1인" 같은
  키워드가 태그에 포함되는지만 봅니다 — 미묘한 뉘앙스(비꼬는 리뷰 등)는
  걸러내지 못합니다.
- 네이버 지역검색 API 특성상 한 번의 검색어로 최대 5개 후보까지만 봅니다.

## 5. 자주 겪는 문제

- **`NAVER_HUB_KEY_ID / NAVER_HUB_KEY 환경변수가 설정되어 있지 않습니다` 오류**:
  위 1번 단계를 다시 확인하세요. `setx`로 설정한 직후라면 새 터미널(새 Claude
  Code 세션)을 열어야 반영됩니다.
- **404 오류(요청 경로를 찾을 수 없음)**: 지역검색 API 경로가 추정값이라 실제와
  다를 수 있습니다. NCP 콘솔에서 지역검색 API 예제 코드의 실제 경로를 확인해서
  `scripts/search_naver_places.js`의 `API_URL`을 고쳐주세요.
- **추천 결과가 너무 적음**: 지역명을 더 넓게(예: 역 이름 대신 동네 이름) 다시
  요청해보세요.
