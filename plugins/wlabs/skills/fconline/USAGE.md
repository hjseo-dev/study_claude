# fconline 사용법

FC 온라인(EA SPORTS FC 온라인) 최근 10경기 전적을 넥슨 오픈API로 조회해서,
감독처럼 포메이션/전술/선수 보강 방향을 분석해주는 스킬입니다.

## 1. 사전 준비: FCONLINE_KEY 발급

1. [openapi.nexon.com](https://openapi.nexon.com)에서 넥슨 계정으로 로그인
2. 애플리케이션 등록 → API 키 발급 (무료)
3. 환경변수로 등록 (PowerShell, 영구 설정 - 새 터미널부터 적용됨)

   ```powershell
   setx FCONLINE_KEY "발급받은_API_키"
   ```

   방금 설정했다면 **새 터미널을 열어야** 반영됩니다. 기존 터미널에서 바로
   써야 한다면 그 세션에서만 `$env:FCONLINE_KEY = "발급받은_API_키"`로 임시
   지정할 수 있습니다.

## 2. 호출 방법

Claude Code에서 아래 슬래시 명령을 입력합니다.

```
/wlabs:fconline
```

(플러그인 이름과 스킬 이름을 콜론으로 이은 형식입니다.)

이 스킬은 "내 전적 분석해줘" 같은 말을 해도 자동으로는 실행되지 않습니다
(SKILL.md의 `disable-model-invocation: true` 설정). 위 슬래시 명령으로
명시적으로 불러야 합니다.

이 스킬은 서브에이전트(포크)로 분리 실행됩니다. 10경기치 원본 API 응답은
용량이 커서 메인 대화창에는 요약된 분석 결과만 전달되고, 원본 JSON은
서브에이전트 안에서만 다뤄집니다.

## 3. 첫 실행 시: 닉네임 입력

처음 실행하면 저장된 닉네임이 없어서 Claude가 "FC 온라인 게임 닉네임"을
물어봅니다.

- 닉네임은 커밋되지 않습니다.
- 리포 루트의 `.private/`(← `.gitignore`로 커밋 제외)에만 저장됩니다.

  ```
  D:\dev\study_claude\.private\fconline\profile.json
  ```

이 파일은 `.gitignore`에 등록돼 있어서 git으로 추적/커밋되지 않고, 이 리포를
clone한 다른 사용자에게도 공유되지 않습니다. 각자 자기 컴퓨터에서 한 번씩 자기
닉네임을 입력해 세팅하게 됩니다.

## 4. 분석 내용

- 최근 전적(승/무/패)과 최근 폼
- 자주 쓰는 포메이션과 그 포메이션의 성과
- 점유율/패스 성공률/슈팅 정확도 기반 전술 경향·플레이 스타일
- 강점/약점 포지션
- 포메이션·전술 조정 제안
- 보강이 필요한 포지션과 방향성 (특정 선수 카드/가격을 단정하지는 않습니다 —
  시세 API는 호출하지 않기 때문입니다)

기본값은 최근 10경기, matchtype 50(공식경기)입니다. "최근 20경기", "감독모드
기준으로" 등으로 요청하면 조건을 바꿔서 조회합니다.

## 5. 닉네임을 바꾸고 싶을 때

"닉네임 다시 설정해줘", "다른 계정으로 봐줘" 등으로 요청하면 새 닉네임을
물어보고 기존 저장 파일을 덮어씁니다.

## 6. 자주 겪는 문제

- **`FCONLINE_KEY가 설정되어 있지 않습니다` 오류**: 위 1번 단계를 다시
  확인하세요. `setx`로 설정한 직후라면 새 터미널(새 Claude Code 세션)을
  열어야 반영됩니다.
- **닉네임 조회 실패**: 닉네임 철자가 정확한지 확인하고 "닉네임 다시
  설정해줘"로 재입력해보세요.
- **선수 이름이 숫자(spId)로만 나옴**: 넥슨의 선수 메타데이터(spid.json)
  조회에 실패한 경우로, 분석 자체에는 영향이 없습니다.
