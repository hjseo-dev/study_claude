# 금융감독원 "금융상품 한눈에"(finlife) API 필드 참고

`https://finlife.fss.or.kr` 의 금융상품통합비교공시 오픈API. 정기예금과
적금 각각 별도 엔드포인트가 있다 (2026-08-30 웹 문서 기준 정리 — 문서 자체가
엔드포인트/필드를 완전히 상세하게 공개하지 않아, `scripts/fetch_products.js`를
처음 실행할 때 실제 응답을 한 번 찍어보고 아래 내용과 다르면 이 문서를 갱신한다).

## 인증키

[finlife.fss.or.kr](https://finlife.fss.or.kr) → 오픈API → 인증키 신청에서
32자리 인증키를 무료로 발급받는다. 환경변수 `FINLIFE_API_KEY`로 등록한다.

## 권역 코드 (topFinGrpNo)

| 코드 | 권역 | 비고 |
| --- | --- | --- |
| 020000 | 은행 | 1금융권 |
| 030300 | 저축은행 | 2금융권(가장 대표적인 저축상품 취급 권역) |

"2금융권"은 넓게는 신협/새마을금고/상호금융 등도 포함하지만, finlife API가
지원하는 권역 중 예적금 비교에 가장 흔히 쓰이는 건 저축은행(030300)이다.
사용자가 신협 등을 콕 집어 요청하면 별도 코드가 필요할 수 있음을 안내한다.

## 응답 구조 (baseinfo + options)

상품마다 `baseinfo`(상품 공통 정보) 1개 + `options`(가입기간별 금리 옵션) N개로 구성된다.
즉 한 상품이 6개월/12개월/24개월 옵션을 모두 제공하면 `options` 배열에 3개 항목이 온다.

**baseinfo 주요 필드**
- `kor_co_nm`: 금융회사명
- `fin_prdt_nm`: 상품명
- `join_way`: 가입방법
- `join_member`: 가입대상(가입 가능한 사람 설명, 자유 텍스트)
- `spcl_cnd`: 우대조건(자유 텍스트) — 우대금리를 받기 위한 조건, 때로 한도/이벤트 정보도 섞여 있음
- `mtrt_int`: 만기 후 이율 안내
- `dcls_strt_day` / `dcls_end_day`: 공시 시작일/종료일 (⚠ 이벤트 종료일이 아니라 "이 조건이 공시된 기간"이다 — 헷갈리지 않게 "공시 종료일(참고용)"이라고 표시한다)
- `max_limit`: 최고한도금액(정기예금 쪽에서 확인됨; 적금 쪽에도 있는지는 실제 응답으로 확인 필요)

**options 주요 필드**
- `save_trm`: 저축기간(개월)
- `intr_rate`: 기본금리(연%)
- `intr_rate2`: 최고우대금리(연%, 우대조건 다 만족했을 때 최종금리)
- `intr_rate_type`: 이자계산방식 (S=단리, M=복리)
- `rsrv_type`: 적립유형 (S=정액적립, F=자유적립) — 적금에만 있음

## 이 API가 명확히 안 주는 것 (추정/파싱이 필요한 것)

- **이벤트성 여부·이벤트 종료일**: 별도 필드 없음. `fin_prdt_nm`/`spcl_cnd`에
  "특판", "이벤트", "한정", "선착순" 같은 키워드가 있으면 "이벤트성으로 추정"
  이라고만 표시한다 (확정 아님).
- **적금의 월 최대납입한도**: 별도 필드로 확인 안 됨. `spcl_cnd` 텍스트에서
  "월 최대 OO만원", "월 OO만원 한도" 같은 패턴을 정규식으로 찾아보고, 못
  찾으면 "명시 안 됨"이라고 정직하게 표시한다.

이 두 항목은 정확도를 보장할 수 없으므로, 결과를 보여줄 때 항상 "추정" 또는
"명시 안 됨"이라고 명확히 구분해서 표시하고, 사용자가 실제 가입 전 반드시
은행 상품설명서로 재확인하도록 안내한다.
