# goal-saving-planner 사용법

## 1. 준비물

없음. 외부 API를 쓰지 않고, 사용자가 직접 입력한 금리/수익률 가정치로만
계산한다.

## 2. 호출 방법

`/wlabs:goal-saving-planner` (자동 트리거 없음, 명령어로만 실행됨 — 월급 같은
개인 재무정보를 다루기 때문)

## 3. 흐름

1. **처음 실행 시**: 월급, 고정비/즉시지출/생활비/부가세모으기, 그리고 현재
   진행 중인 저축상품(있다면 이름·금액·금리·남은기간·단리/복리)을 물어봄 →
   `.private/`(← `.gitignore`로 커밋 제외) 개인 설정 파일에 저장
2. **두 번째부터**: 저장된 값을 보여주고 그대로 쓸지/바꿀지 확인
3. 매번: 목표금액, 목표기간(년), 새로 저축할 돈을 나눠 넣을 상품들(예금/적금/
   투자 등, 각각 금액·예상수익률·기간·단리복리)을 물어봄
4. 계산 결과: 여유자금 / 목표달성 필요 월저축액 / **카드값 한도**를 먼저 제시,
   이어서 연 3.3% 적금에 넣었을 때 비교 예시, 그리고 기존+신규 저축을 합친
   1/3/5/10/15/20/25/30년 후 자산 규모 표

## 4. 결과 예시

```
📊 이번 달 기준
- 여유자금: 1,900,000원
- 목표(1억원, 10년) 달성에 필요한 월저축액: 833,333원
- 💳 카드값 한도: 1,066,667원

📈 30년 자산 시뮬레이션 (세전, 만기 시 같은 조건으로 재예치 가정)
| 연도 | 청년적금(기존) | 적금A(신규) | ETF투자(신규) | 합계 |
|---|---|---|---|---|
| 1년 | 3,687,750 | 4,904,000 | 3,739,462 | 12,331,212 |
| 10년 | 8,101,249 | 13,604,890 | 52,228,348 | 73,934,487 |
| 30년 | 19,345,772 | 29,371,936 | 368,126,260 | 416,843,968 |

참고: 목표저축액(833,333원) 전액을 연 3.3% 적금에만 넣었다면 10년 후
116,637,453원 (단리, 목표기간만큼만 적립 가정)
```

## 5. 자주 겪는 문제

- **"신규 배분 합계가 필요 월저축액과 다릅니다" 경고**: 배분한 상품들의 월납입액
  합이 목표달성에 필요한 저축액과 안 맞을 때 뜬다. 카드값 한도를 넘겨 배분했거나
  덜 배분한 것이니 다시 나눠보라고 안내받는다.
- **기존 저축이 여러 개인데 헷갈림**: 하나씩 순서대로 이름·유형·금액·금리·
  남은기간·단리복리를 물어보므로, 한 번에 다 말해도 되고 하나씩 답해도 된다.
- **수익률을 모르겠음**: 이 스킬은 실제 은행 상품을 조회하지 않는다. 대략적인
  가정치(예: 예금/적금 3~4%대)로 먼저 돌려보고, 실제 상품 금리가 궁금하면
  `/wlabs:savings-compare`를 따로 써야 한다.
- **30년치 숫자를 전부 보고 싶음**: 기본은 이정표 연도(1/3/5/10/15/20/25/30년)만
  보여준다. "전체 연도별로 다 보여줘"라고 요청하면 나머지도 보여준다.

## 6. 개선 아이디어

- 이자소득세(15.4%) 반영 옵션
- 물가상승률을 반영한 실질가치 환산
- 실제 예금/적금 상품 금리를 `savings-compare`와 연동해 자동으로 채워주는 옵션
