# 사용 예시: design-base-color

## 시나리오

새 앱을 만드는데 "우리 회사 로고와 어울리는 컬러팔레트를 정하고 싶어"

## 실행

```
/wlabs:design-base-color
```

## 진행 과정

### 1단계: 자산 수집
```
사용자 입력:
- 로고 파일 3개 업로드
- "우리 마스코트는 주황색 고양이예요"
- "기존엔 검정+주황을 썼는데..."
```

### 2단계: 팔레트 후보 제시
```
제안: 5가지 팔레트
- Option 1: 진주황(#EA580C) + 크림 배경
- Option 2: 연주황(#F59E0B) + 아이보리
- Option 3: 따뜻한 회색(#A8A29E) + 연베이지
- Option 4: 심플 검정(#1F2937) + 흰색
- Option 5: 혼합(주황 + 검정 포인트)
```

### 3단계: 대시보드 목업 보여주기
```
HTML 아티팩트로 각 팔레트의 대시보드 모습을 탭으로 전환해서 확인
```

### 4단계: 반복 피드백
```
사용자: "1번 색상은 좋은데 배경이 너무 어두워요"
→ 배경 밝게 조정한 새 버전 만들기

사용자: "흰색 배경에 주황색 포인트만 있으면 좋겠어"
→ 극단적으로 심플하게 재구성
```

### 5단계: 확정 및 저장
```
최종 팔레트 JSON:
{
  "primary": "#B8621B",
  "secondary": "#E8A25D",
  "background": "#FAFAF9",
  "accent": "#FDECD8",
  "text": "#2C3E50"
}

저장 위치:
- docs/color-palettes.html
- docs/color-palettes.json (선택)
```

## 언제 쓰나

- ✅ 신규 앱 개발 시작 (디자인 기본 방향 정할 때)
- ✅ 기존 앱 리브랜딩 (새 로고에 맞춰 컬러 변경)
- ✅ 다중 테마 시스템 (라이트/다크 모드 각각의 팔레트)
- ❌ 이미 정해진 디자인 시스템 미세 조정 (이건 수동 색상 튜닝)
