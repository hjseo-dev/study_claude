# jeju-trip-plan 사용법

제주도 숙소 주소(또는 숙소 이름)와 여행 박/일 수를 입력하면, 숙소 근처
지역의 관광지·음식점을 네이버 지역검색 API로 찾아 날짜별 일정을 짜주는
스킬입니다. 공식 관광지 카탈로그가 아니라 **리뷰 많은 순(sort=comment)**으로
조회해서, 실제 사람들이 많이 찾는 곳 위주로 추천합니다.

## 1. 사전 준비: NAVER_HUB_KEY_ID / NAVER_HUB_KEY 발급

cafe-with-study 스킬을 이미 쓰고 있다면 **같은 키를 그대로 재사용**하면
됩니다. 처음이라면:

1. [NAVER Cloud Platform](https://www.ncloud.com) 가입
2. 콘솔의 **Services > AI·NAVER API** 메뉴에서 **Application 등록**
3. 사용할 API로 **지역검색(Search) API** 선택
4. 발급된 **Client ID / Client Secret**을 각각 환경변수로 등록

```powershell
setx NAVER_HUB_KEY_ID "발급받은_Client_ID"
setx NAVER_HUB_KEY "발급받은_Client_Secret"
```

방금 설정했다면 **새 터미널(새 Claude Code 세션)**을 열어야 반영됩니다.

> 2026년 개편으로 예전 개발자센터(openapi.naver.com)는 신규 발급이 막혔고,
> 반드시 NAVER Cloud Platform(NAVER API HUB)을 통해서만 새로 발급받을 수
> 있습니다.

## 2. 호출 방법

```
/wlabs:jeju-trip-plan
```

이 스킬은 "제주 여행 일정 짜줘" 같은 말에 자동으로는 실행되지 않습니다
(`disable-model-invocation: true`). 위 슬래시 명령으로 명시적으로 불러야
합니다.

실행하면 Claude가 숙소 주소(또는 숙소 이름)와 몇박 며칠인지 물어봅니다.
미리 대화에서 언급했다면 다시 묻지 않습니다. 도로명 주소가 없어도 숙소
이름만으로 시도합니다(스크립트가 먼저 그 이름으로 검색해 주소를 찾아냄).

## 4. 자주 겪는 문제

- **`NAVER_HUB_KEY_ID / NAVER_HUB_KEY가 설정되어 있지 않습니다` 오류**: 위
  1번 단계를 다시 확인하세요. `setx` 직후라면 새 터미널을 열어야 반영됩니다.
- **404 오류(API 경로를 찾을 수 없음)**: 스크립트의 지역검색 API 경로는
  공식 문서로 100% 확정하지 못한 추정값입니다. NCP 콘솔에서 지역검색 API를
  선택했을 때 나오는 예제 코드의 실제 요청 경로를 확인해서
  `scripts/find_places.js`의 `API_URL` 상수를 그 값으로 고쳐야 합니다.
- **"입력에서 지역명을 찾지 못했습니다"(needMoreInfo)**: 숙소 주소/이름이
  너무 축약되어 있어 "제주시"인지 "서귀포시"인지조차 못 찾은 경우입니다
  (원도심 도로명주소처럼 읍/면/동이 안 나오는 정도는 자동으로 시/군 단위로
  대체되므로 여기 해당하지 않습니다). "제주시 애월읍", "서귀포 KAL호텔
  근처"처럼 시/군 정도는 구분되게 다시 알려주세요.
- **관광지/음식점이 거의 안 나옴**: 읍/면/동 단위로 검색해서 부족하면
  스크립트가 자동으로 시/군(제주시/서귀포시) 단위로 넓혀 재검색합니다
  (`broadenedToCityLevel: true`). 그래도 부족하면 실제로 리뷰가 적게
  등록된 지역일 수 있습니다.
- **관광지 목록에 관광지가 아닌 게 섞여 있다**: 네이버 지역검색은 검색어
  기반이라 가끔 무관한 업체가 섞입니다. Claude가 `category` 필드를 보고
  걸러내지만, 눈에 띄면 "○○은 빼줘"라고 요청하면 됩니다.
- **일정이 지리적으로 뒤죽박죽인 것 같다**: 좌표/경로 API를 쓰지 않고
  주소 지역명 문자열만으로 묶습니다. 마음에 안 드는 배치가 있으면
  "○○이랑 ○○을 같은 날로 묶어줘"처럼 직접 조정을 요청하면 됩니다.

## 5. 개선 아이디어 (아직 구현 안 됨)

- Tmap 경로 API로 실제 이동 시간까지 고려해 날짜/순서를 더 정교하게 짤 수
  있습니다.
- 계절/날씨(예: 우천 시 실내 위주)를 반영하고 싶다면 weather/umbrella
  스킬 결과와 조합해볼 수 있습니다.
- cafe-with-study처럼 네이버 플레이스 리뷰 태그까지 스크래핑하면 "아이랑
  가기 좋음", "노키즈존" 같은 세부 취향 필터도 가능하지만, 호출 수가 늘어
  현재는 넣지 않았습니다.
