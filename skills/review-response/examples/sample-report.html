최신 코드 확인

지금도 registerStompEndpoints()에서 .setAllowedOriginPatterns("*")로 모든 출처를 허용 중 — 문제가 여전히 남아있음을 확인.

연관 코드 조사

이 엔드포인트(/wsConnect)는 채팅 기능(ChatController, ChatService, ChatRoomManager, ChatDTO/ChatRoom)이 사용 중. 도메인 제한으로 바꿔도 이 클래스들의 로직 변경은 필요 없고, 정상 도메인에서는 계속 연결되는지 회귀 확인만 필요.

판단 및 근거

실제로 Cross-Site WebSocket Hijacking 위험이 있는 설정이 맞음. Critical이므로 재판단 없이 반영 필요.

최신 코드 확인

프로젝트 전체에 @ControllerAdvice/@RestControllerAdvice가 하나도 없음을 확인 — 각 컨트롤러가 개별 try/catch로 처리 중인 것은 사실.

연관 코드 조사

전역 예외 처리로 옮기려면 사실상 모든 컨트롤러(수십 개)의 try/catch 블록을 걷어내야 하는 프로젝트 전역 리팩터링 규모 — 이번 리뷰가 달린 범위(개별 기능 PR)를 크게 벗어남.

반영 안 함 — 근거

제안 자체는 타당하고 장기적으로는 맞는 방향이지만, 이번 PR의 목적과 무관한 프로젝트 전역 구조 변경. 범위 밖으로 분류하고, 별도 기술 부채 항목으로 분리 제안.
