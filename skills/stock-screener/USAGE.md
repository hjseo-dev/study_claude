# stock-screener 사용법

관심종목 또는 즉석 입력한 국내(코스피/코스닥) 종목의 **재무제표**(DART)와
**시세**(공공데이터포털)를 조회해, ROE·부채비율·이자보상배율 등으로 재무
건전성(우량기업 여부)을 스크리닝하고 PER·PBR·PEG로 밸류에이션을 계산하는
스킬입니다. 투자자문이 아니라 객관적 지표 제공용입니다.

## 1. 사전 준비: 인증키 발급

두 개의 키가 필요합니다.

1. **DART_API_KEY**
   - [opendart.fss.or.kr](https://opendart.fss.or.kr) 가입
   - 오픈API 이용신청 (무료, 즉시 발급)
   - 발급받은 인증키를 `DART_API_KEY`로 등록

2. **STOCK_API_KEY**
   - [data.go.kr](https://www.data.go.kr) 가입
   - "금융위원회_주식시세정보" 검색 후 활용신청 (무료)
   - 마이페이지 > 데이터 활용 > Open API 개발계정 상세보기에서 서비스키
     확인 후 `STOCK_API_KEY`로 등록
   - **wlabs의 stock-picks 스킬을 이미 쓰고 있다면 이 키를 그대로
     재사용합니다** — 새로 발급받을 필요 없음.

PowerShell (영구 설정, 새 터미널부터 적용):

```powershell
setx DART_API_KEY "발급받은_DART_키"
setx STOCK_API_KEY "발급받은_공공데이터포털_서비스키"
```

## 2. 호출 방법

```
/wlabs:stock-screener
```

인자 없이 호출하면 저장된 관심종목 전체를 조회합니다. 관심종목이 없으면
등록을 안내합니다.

```
/wlabs:stock-screener 삼성전자 000660
```

종목명 또는 6자리 종목코드를 인자로 주면 그 종목만 즉석 조회합니다(관심종목
등록 없이도 됩니다).

"이 종목 우량기업이야?", "삼성전자 재무제표 봐줘", "관심종목 PER PBR
알려줘" 같은 말로도 자동 실행됩니다.

### 관심종목 관리

```
node <스킬 디렉터리>/scripts/set_watchlist.js "삼성전자,005930" "SK하이닉스,000660"
node <스킬 디렉터리>/scripts/set_watchlist.js --show
node <스킬 디렉터리>/scripts/set_watchlist.js --clear
```

## 3. 데이터 소스

- **재무제표**: DART(금융감독원) 오픈API `fnlttSinglAcntAll.json`. 최근
  사업보고서(연간) 기준, 연결재무제표(CFS) 우선 조회 후 없으면 별도(OFS)로
  대체합니다.
- **시세/시가총액**: 공공데이터포털 "금융위원회_주식시세정보"
  (`getStockPriceInfo`). 실시간이 아니라 **최근 영업일 기준**입니다.
- PER/PBR은 이 두 데이터를 조합해(시가총액 ÷ 순이익/자본총계) 직접
  계산합니다. PEG는 전기 대비 이익 증가율 기준 **과거 성장률 근사치**이며
  미래 이익 추정치가 아닙니다.

## 4. 결과 예시

```
📌 삼성전자 (005930)
📊 ROE 12.3% · 부채비율 38% · 이자보상배율 45배 → 재무 건전성 양호
💰 PER 14.2 · PBR 1.3 · PEG 1.1(과거 성장률 기준 근사)

재무 데이터 기준 객관적 지표이며 투자 추천이 아닙니다.
```

## 5. 한계 / 유의사항

- **국내(코스피/코스닥)만** 지원합니다. 해외 종목은 안 됩니다.
- DART 재무제표는 **공시 시점 기준**이라 최신 분기 실적이 아직 반영 안 됐을
  수 있습니다(사업보고서는 회계연도 종료 후 약 3개월 뒤 공시).
- 계정과목명(`account_nm`)이 회사/업종마다 달라 일부 종목은 이자비용·CAPEX
  항목을 못 찾아 이자보상배율/FCF 계산이 생략될 수 있습니다.
- 시세 API의 정확한 필드명은 공개 문서 기준이고 실제 서비스키로 완전히
  검증되진 않았습니다(`references/api-fields.md` 참고). 값이 이상하면 원본
  응답 구조가 문서와 다를 수 있습니다.
- PEG는 미래 추정 성장률이 아니라 **과거 실적 기준 근사치**입니다.
- 이 스킬은 **투자자문이 아닙니다.** 매수/매도 시점이나 개인 맞춤 조언은
  제공하지 않습니다.
