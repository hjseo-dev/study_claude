# 재무제표 기반 우량기업 스크리닝 + PER/PBR/PEG

DART(금융감독원) 오픈API의 재무제표와 공공데이터포털의 시세 데이터를 조합해,
관심종목 또는 즉석 입력한 국내(코스피/코스닥) 종목의 재무 건전성(우량기업
여부)과 밸류에이션(PER/PBR/PEG)을 스크리닝한다.

> **이 스킬은 투자자문이 아니다.** 재무 데이터에 근거한 객관적 지표만
> 제공하며, 매수/매도 시점이나 개인 맞춤 조언은 하지 않는다.

> 관심종목/조회 결과는 이 리포지토리(GitHub에 공개됨) 안 어디에도 저장하지
> 않는다. 항상 사용자 홈 디렉터리(리포 밖)의 로컬 캐시/설정 파일에만 저장한다.

## 실행 방법

1. 환경변수 `DART_API_KEY`와 `STOCK_API_KEY`가 설정되어 있는지 확인한다.
   하나라도 없으면 아래 "인증키 설정" 안내를 사용자에게 보여주고 중단한다.

   Windows에서는 `setx`로 설정한 시스템/사용자 환경변수가 이미 실행 중인
   셸 프로세스에는 바로 반영되지 않을 수 있다. 일반 조회로 값이 안 보이면,
   포기하기 전에 PowerShell에서
   `[System.Environment]::GetEnvironmentVariable("DART_API_KEY", "Machine")`
   (또는 `"User"`)로 시스템에 실제로 등록되어 있는지 먼저 확인하고, 있다면
   그 값을 스크립트를 실행할 자식 프로세스의 환경변수로 넣어 실행한다.

2. 이 스킬 디렉터리의 `scripts/fetch_screening.js`를 Node.js로 실행한다.
   (스킬 로드 시 표시되는 "Base directory for this skill" 경로를 기준으로
   삼는다.)

   ```
   node <스킬 디렉터리>/scripts/fetch_screening.js [종목명 또는 종목코드 ...]
   ```

   - 사용자가 이번 대화에서 구체적인 종목(예: "삼성전자", "005930")을
     언급했다면 그 이름/코드를 인자로 넘긴다. 여러 개면 공백으로 구분해
     여러 인자로 넘긴다.
   - 특정 종목 언급 없이 "관심종목 재무 스크리닝해줘"처럼 요청했다면 인자
     없이 실행한다 — 저장된 관심종목 전체를 조회한다.

   최초 실행 시 DART `corp_code` 매핑 캐시를 내려받느라 다소 시간이 걸릴 수
   있다(수십 초). 이후에는 로컬 캐시(7일 유효)를 재사용해 빠르다.

3. 인자 없이 실행했는데 관심종목이 비어 있으면 스크립트가 에러 메시지로
   안내한다. 이 경우 사용자에게 조회하고 싶은 종목(이름 또는 6자리
   종목코드)을 물어보고, 아래 명령으로 저장한 뒤 다시 2번을 실행한다.

   ```
   node <스킬 디렉터리>/scripts/set_watchlist.js "삼성전자,005930" "SK하이닉스,000660"
   ```

   `이름,종목코드` 형식으로 여러 개를 한 번에 넘길 수 있다. 이미 저장된
   코드와 겹치면 덮어쓴다. 정확한 종목코드를 모르면, 이름만으로도
   `fetch_screening.js`에 바로 넘겨 조회할 수 있으니(자동 매핑) 굳이 먼저
   `set_watchlist.js`를 쓸 필요는 없다 — 관심종목으로 "저장"해서 다음에도
   반복 조회하고 싶을 때만 쓴다.

4. `resolveErrors` 배열을 확인한다. 이름이 여러 종목에 매칭되면(`candidates`
   포함) 사용자에게 후보를 보여주고 정확한 종목을 골라달라고 물어본 뒤,
   확정된 6자리 코드로 다시 실행한다. 매핑을 아예 못 찾으면(상장폐지/오타
   가능성) 해당 종목은 결과에서 제외했다고 솔직히 알린다.

5. `results[]`의 각 항목은 가공되지 않은 raw 데이터다. **계산에 들어가기
   전에 먼저 실제 구조를 확인**한다:

   - `dart.list`: DART `fnlttSinglAcntAll.json` 응답의 계정과목 배열
     (`account_nm`, `account_id`, `thstrm_amount`(당기), `frmtrm_amount`(전기),
     `sj_nm`(재무제표 구분: 재무상태표/손익계산서/현금흐름표) 등). 정확한
     `account_nm` 문구는 회사·업종마다 다를 수 있으므로(예: "당기순이익"
     vs "반기순이익", "이자비용"이 아예 없을 수도 있음), 먼저 해당 종목의
     `account_nm` 유니크 목록을 훑어본 뒤 아래 항목에 해당하는 것을 찾는다.
     `dart.ok`가 `false`면 `dart.attempts`를 보고 어느 연도/구분에서 실패했는지
     확인하고, 데이터가 없다고 솔직히 안내한다(추정치를 지어내지 않는다).
   - `price`: 공공데이터포털 "금융위원회_주식시세정보" 응답 원본 한 건.
     `clpr`(종가), `mrktTotAmt`(시가총액), `lstgStCnt`(상장주식수)로 알려져
     있으나 문서 기준일 뿐 실제 검증은 안 됐다 — 필드가 실제로 있는지, 숫자로
     잘 파싱되는지 먼저 확인한다. `null`이면 해당 종목의 시세를 못 찾은
     것이다(신규상장/코드 오류 가능).

   **최초 실행에서 확인한 실제 필드명/계정과목명은
   [references/api-fields.md](references/api-fields.md)에 기록해 다음
   실행부터는 바로 참고한다** (이미 기록되어 있으면 그대로 신뢰하고 재확인
   생략).

6. 확인한 필드로 아래를 계산한다. 필요한 계정을 못 찾으면 억지로 계산하지
   말고 "해당 항목 계산 불가"라고 명시한다.

   - **ROE** = 당기순이익 / 자기자본(자본총계) × 100
   - **부채비율** = 부채총계 / 자본총계 × 100
   - **영업이익률** = 영업이익 / 매출액 × 100
   - **순이익률** = 당기순이익 / 매출액 × 100
   - **이자보상배율** = 영업이익 / 이자비용. **DART 재무제표에는 대개
     "이자비용" 단독 항목이 없다** (2026-09-02 라이브 검증, 삼성전자 기준).
     대신 있는 "금융비용"(외화환산손실 등도 포함된 더 넓은 개념)으로
     근사 계산하고, 결과에 "금융비용 기준 근사치"라고 명시한다. 그마저도
     없으면 계산을 생략하고 그 사실을 알린다.
   - **FCF(잉여현금흐름)** = 영업활동현금흐름 − CAPEX(유형자산의 취득 등,
     현금흐름표 투자활동 항목에서 확인). 항목이 없으면 계산 생략.
   - **PER** = 시가총액 / 당기순이익 (또는 종가 / EPS, EPS = 당기순이익 /
     상장주식수 — 둘 다 같은 값이어야 하니 교차검증 가능하면 한다)
   - **PBR** = 시가총액 / 자본총계
   - **PEG** = PER / (전기 대비 당기순이익(또는 EPS) 증가율(%)). **주의:**
     공식 API로는 미래 이익 추정치를 구할 수 없으므로 이 PEG는 "과거 실적
     성장률 기준 근사치"다. 결과에 이 한계를 반드시 한 줄로 명시한다.
     전기 순이익이 0 이하이거나 흑자전환/적자전환인 경우 성장률이 무의미해
     지므로 PEG 계산을 생략하고 그 사유를 밝힌다.

7. 결과는 종목별로 섹션을 나눠 한국어로 정리한다. 각 결과 줄 앞에 어울리는
   이모지를 붙이고(예: 📊 재무 건전성, 💰 밸류에이션), 여러 종목을 비교할 때
   가장 우량하거나 저평가된 쪽을 강조하려면 "⭐ "로 시작하는 줄을 쓴다. 예:

   ```
   📌 삼성전자 (005930)
   📊 ROE 12.3% · 부채비율 38% · 이자보상배율 45배 → 재무 건전성 양호
   💰 PER 14.2 · PBR 1.3 · PEG 1.1(과거 성장률 기준 근사)
   ```

   맨 마지막에 "재무 데이터 기준 객관적 지표이며 투자 추천이 아닙니다" 같은
   한 줄을 덧붙인다.

   `error: true`이면 `message`를 그대로 전달하고, 원인(인증키 미설정/만료,
   corp_code 매핑 실패, API 오류 등)에 맞는 다음 행동을 제안한다.

8. 관심종목을 바꾸고 싶다는 요청(예: "관심종목에 추가해줘", "이 종목 빼줘")을
   받으면 `set_watchlist.js`로 추가/덮어쓰기 하거나(현재는 개별 삭제 기능은
   없고 `--clear`로 전체 삭제 후 재등록만 가능하다는 점을 필요하면 안내),
   `--show`로 현재 목록을 확인해 사용자에게 보여준다.

## 인증키 설정

두 개의 키가 필요하다.

**1) DART_API_KEY** — [opendart.fss.or.kr](https://opendart.fss.or.kr)에서
회원가입 후 오픈API 이용신청을 하면 발급된다. 무료.

**2) STOCK_API_KEY** — [data.go.kr](https://www.data.go.kr) 가입 후
"금융위원회_주식시세정보" 검색해서 활용신청하면 발급된다. 무료. (stock-picks
스킬을 이미 쓰고 있다면 이 키를 그대로 재사용한다 — 새로 발급받을 필요 없음.)

PowerShell (영구 설정, 새 터미널부터 적용):

```powershell
setx DART_API_KEY "발급받은_DART_키"
setx STOCK_API_KEY "발급받은_공공데이터포털_서비스키"
```

## 저장 위치

매핑 캐시(7일 유효)를 리포 루트의 `.private/`(← `.gitignore`로 커밋 제외)에
저장한다:
